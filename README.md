# Ouro Play — distribuição

Arquivos lidos pelos aparelhos dos clientes. Não edite à mão sem conferir o JSON:
um `config.json` inválido é ignorado pelos boxes (eles mantêm a última versão boa).

- `config.json`: app principal, banners, atalhos, aviso, WhatsApp e apps gerenciados.
- Releases: os APKs publicados, com SHA-256 conferido pelo launcher antes de instalar.
